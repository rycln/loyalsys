# Gofermart Loyalty System

## Описание проекта

Накопительная система лояльности «Гофермарт» — это HTTP API сервис для управления баллами лояльности пользователей. Система позволяет пользователям регистрироваться, загружать номера заказов, получать начисления баллов и использовать их для оплаты будущих покупок.

## Основные возможности

- ✅ Регистрация и аутентификация пользователей (JWT)
- ✅ Загрузка номеров заказов для начисления баллов
- ✅ Получение списка заказов с статусами обработки
- ✅ Управление балансом баллов лояльности
- ✅ Списание баллов для оплаты заказов
- ✅ Интеграция с внешней системой расчёта начислений (Accrual System)
- ✅ История списаний
- ✅ Автоматическая синхронизация статусов заказов с внешним сервисом

## Технологический стек

- **Go 1.23** - основной язык разработки
- **PostgreSQL** - реляционная база данных
- **fiber** - маршрутизация HTTP-запросов
- **JWT** - аутентификация пользователей
- **bcrypt** - хеширование паролей
- **goose** - миграции базы данных
- **zap** - структурированное логирование

## Конфигурация

Сервис поддерживает гибкую конфигурацию через **переменные окружения** и **флаги командной строки** с приоритетом переменных окружения.

### Параметры конфигурации:

**RUN_ADDRESS / -a**  
*Описание:* Адрес и порт запуска HTTP сервера  
*По умолчанию:* `:8080`  

**DATABASE_URI / -d**  
*Описание:* Строка подключения к PostgreSQL  
*По умолчанию:* не задано (обязательный параметр)  

**ACCRUAL_SYSTEM_ADDRESS / -r**  
*Описание:* URL внешней системы начислений (Accrual)  
*По умолчанию:* не задано (обязательный параметр)  

**TIMEOUT_DUR / -t**  
*Описание:* Таймаут операций в системе  
*По умолчанию:* `2m` (2 минуты)  

**JWT_KEY / -k**  
*Описание:* Секретный ключ для подписи JWT токенов  
*По умолчанию:* Автоматически генерируется 32-байтный ключ  
*Примечание:* При использовании сгенерированного ключа в логах будет предупреждение

**LOG_LEVEL / -l**  
*Описание:* Уровень детализации логов  
*По умолчанию:* `debug`  
*Допустимые значения:* `debug`, `info`, `warn`, `error`
